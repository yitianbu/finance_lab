# 公告策略纸面实盘设计

## 目标

把当前公告回测策略推进到实盘前状态：每天生成可执行买卖清单，经过账户级风控过滤，记录纸面成交、持仓、资金、净值和相对沪深300表现。系统暂不连接券商接口，先用纸面交易验证数据、流程和风控。

## 边界

- 使用当前默认策略 `benchmark_constrained` 作为信号来源。
- 不做真实下单，不保存券商账号或交易密码。
- 输出文件全部放在 `/Users/weifeng/works/finance_lab`。
- 实盘前门槛是流程稳定和风控可审计，不把历史回测收益视为未来收益保证。

## 核心模块

1. 信号生成：读取结构化业绩预告，按策略评分、净利上限、月份过滤、公告前涨幅、开盘缺口和涨跌停近似规则生成候选交易。
2. 风控过滤：限制单票仓位、组合总仓位、单日最大新开仓、黑名单、ST/退市风险、停牌或无行情、价格异常和低流动性。
3. 纸面账本：维护现金、持仓和订单，按计划价或可用日线近似成交，记录买入、卖出、跳过原因和每日净值。
4. 每日报告：输出 `orders.csv`、`positions.csv`、`fills.csv`、`daily_report.md`，说明候选、执行、风控拒绝、持仓和组合风险。
5. 实盘闸门：只有连续纸面运行无数据错误、无风控异常、回撤和相对沪深300表现达标，才考虑下一阶段接入券商接口。

## 数据流

公告事件和日线缓存进入信号生成器；候选交易进入风控层；通过的交易写入纸面订单；纸面执行器更新持仓、现金和成交记录；报告器生成当天审计文件。所有输出可用 CSV 复查。

## 风险控制

默认账户资金 1,000,000 元，单票目标仓位 20%，组合总仓位 80%，单日最多 5 笔新买入，单票最小成交金额 10,000 元。黑名单和 ST/退市风险默认拒绝。若当天无行情或行情日期不新鲜，拒绝生成实盘买入。

## 验证

用单元测试覆盖：

- 风控拒绝 ST、黑名单、组合仓位超限和过小订单。
- 订单数量不超过单日上限。
- 纸面买入会减少现金并增加持仓。
- 每日报告包含订单、持仓、成交和风控摘要。
- CLI 能生成指定日期的纸面交易目录。
